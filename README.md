# 2chみたいな掲示板のサンプルコードですよ。。。

一応2chとは違ってPHP製です。セキュリティ面は危ないと思うので、実用化するときはもっと改変しましょうね。そのまま使う人はいないと思うけど
保存形式はJSONです。threads_data.jsonが保存先です。配列データをjson_encode()でJSON形式に変換して保存して、読み込みはjson_decodeでphp配列に戻してます。
ちなみにほとんどのものは2chのソースのデザインをそのまま使ってるだけです。ほとんどテストもしてないのでなんかあったら報告してね。

使うときは絶対セキュリティ改善するんだよ。これなんもしてないから。
あとめんどくさいからほとんどAIで作ってデザインちょっと改変しただけだから、さらに信用性がないよ(´・ω・`)

## **設置方法**

まず、この掲示板1ファイルでできてるから、このPHPをダウンロードしてサーバーとかに設置すればいいんですよね〜
